# 🌌 Wikiverse

An interactive knowledge explorer powered by the Wikipedia API.

Instead of simply reading Wikipedia, Wikiverse is designed for discovery. Explore random articles, dive into curated categories, follow the famous Philosophy Trail, discover historical events, save your favorite topics, and build your own knowledge journey.

---

## ✨ Features

- 🔍 Live Wikipedia Search
- 🎲 Random Article Discovery
- 📚 Category Explorer
- 🌙 Dark & Light Theme
- ❤️ Like & Favorite Articles
- 💾 Save Articles
- 📜 Recently Viewed History
- 🗣️ Text-to-Speech Reader
- 📅 On This Day
- 🖼️ Picture of the Day
- 🔮 Mystery Explorer
- 🤪 Weird Facts Mode
- 🧭 Philosophy Trail
- 🔁 Auto Roulette
- 🎵 Optional Sound Effects
- 📱 Fully Responsive
- ⚡ Local Caching
- 👤 Offline User Accounts (Local Storage)

---
